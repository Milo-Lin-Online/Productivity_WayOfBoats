🏆 How the World Cup works
• Tap a category's circle each day you do it — that builds your 🔥 streak.
• Miss a day and that streak resets to 0.
• Keep a category checked 26+ days in one month and you catch a 🎣 fish (one per category, per month) — worth 10 leaderboard points.
• Days roll over at midnight Eastern Time (not your computer's clock).
• Everyone sets their own categories — tap "⚙️ my goals" on your card.

  2. Wait ~2 min for it to build.
  3. Left sidebar → SQL Editor → paste & run this:
    create table boats_items (room text, item_key text, data jsonb, updated_at bigint, primary key (room, item_key));
    alter table boats_items enable row level security;
    create policy "all" on boats_items for all using (true) with check (true);
    alter publication supabase_realtime add table boats_items;

    -- keep the old table too; the app reads it once to migrate
    -- (nothing to run if boats_state already exists)
  5. Left sidebar → Project Settings → API.
  6. Copy Project URL → paste above.
